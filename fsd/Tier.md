# 티어메이커 — 작품/배우 티어 평가

## 개요

작품/배우에 티어를 부여하여 평가하는 시스템.
월드컵/마스터랭킹과 독립적으로 운영되며, 마스터 티어는 상세 모달/툴팁에서 공식 티어로 표시.
탭 위치: 파일 다음, 월드컵 앞 (대시보드 / 작품 / 배우 / 파일 / 랭킹 / **티어** / 월드컵 / 레이블 / 태그)

---

## 핵심 구조

### 티어 세트 (Tier Set)
- 하나의 평가 단위 (예: "종합 티어", "장르별 티어")
- `type`: 'actor' | 'work'
- `is_master`: 마스터 티어 여부 (타입별 1개만 가능)
- 마스터 티어 = 작품/배우 상세 모달/툴팁에서 공식 티어로 표시

### 티어 (Tier Level)
- 세트별로 자유 생성 (예: S, A, B, C, D)
- 사용자 정의: 이름, 색상
- `sort_order`로 상하 순서 명확 (낮을수록 상위)
- ID 값으로 관리 → 상세 정보에서 참조

### 배치 (Tier Item)
- 작품/배우를 특정 세트의 특정 티어에 배치
- 같은 티어 내에서도 좌측이 상위 — `sort_order`로 관리 (낮을수록 좌측/상위)
- 드롭 시 놓는 위치에 따라 티어 내 순서가 결정됨
- 미배치 항목은 상세 모달에서 `-` 또는 `#` 표시

## DB 스키마

```sql
CREATE TABLE tier_sets (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  type TEXT NOT NULL CHECK(type IN ('actor', 'work')),
  is_master INTEGER NOT NULL DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now'))
);

CREATE TABLE tier_levels (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  set_id INTEGER NOT NULL REFERENCES tier_sets(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  color TEXT NOT NULL,
  sort_order INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE tier_items (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  set_id INTEGER NOT NULL REFERENCES tier_sets(id) ON DELETE CASCADE,
  level_id INTEGER NOT NULL REFERENCES tier_levels(id) ON DELETE CASCADE,
  item_id INTEGER NOT NULL,
  sort_order INTEGER NOT NULL DEFAULT 0,
  UNIQUE(set_id, item_id)
);
```

### 제약 조건
- `tier_sets`: 타입별 `is_master = 1`은 1개만 허용
- `tier_items`: 같은 세트에 같은 아이템은 1번만 배치 가능
- `tier_levels.sort_order`: 낮을수록 상위 (S=0, A=1, B=2...)

## 기능

### 1. 티어 세트 관리
- 생성: 이름, 타입(작품/배우), 마스터 여부
- 수정: 이름 변경
- 삭제: 세트 삭제 시 티어+배치 전부 CASCADE 삭제
- 마스터 지정: 타입별 1개만, 기존 마스터 해제 후 지정

### 2. 티어 관리
- 세트 내에서 티어 생성: 이름, 색상, 순서
- 티어 수정: 이름, 색상 변경
- 티어 삭제: 해당 티어의 배치 항목도 삭제
- 순서 변경: ∧∨ 버튼으로 상하 이동

### 3. 아이템 배치
- 작품/배우를 티어에 배치 (드래그 앤 드롭)
- 드롭 위치에 따라 티어 내 좌우 순서 결정 (좌측이 상위)
- 같은 티어 내에서 드래그로 좌우 순서 변경 가능
- 티어 간 이동
- 배치 해제 (미배치로 되돌리기)
- 미배치 항목 풀 표시

### 4. 상세 모달 연동
- 작품/배우 상세 모달: 이름 오른쪽에 마스터 티어 표시 — `배우명 [S+]` (티어 색상 배경 뱃지)
- 미배치 시 `-` 또는 `#` 표시

### 5. CardTooltip 연동
- 배우/작품명 오른쪽에 마스터 티어 표시 — bold 문자에 티어 색상 적용 (배경 아님)

### 6. 대시보드 연동 (추후)
- 마스터 티어 기반 분포 차트 등

## UI

### 화면 구성
1. **세트 목록 화면** — 마스터 티어(고정) + 일반 티어 목록 + 새 티어 생성
2. **티어 편집 화면** — 티어 행 + 아이템 배치 + 미배치 풀

### 세트 목록 화면

**상단 바** (월드컵과 동일한 3블록 구조):
```
[정렬▽][↑] [배우|작품][마스터|일반][전체] [+ 티어 등록]
```
- 좌측: 정렬 셀렉트+방향 (bg-gray-800 컨테이너)
- 중앙: 토글 필터 버튼 (bg-gray-800 컨테이너)
  - 각 버튼은 독립 토글 (on/off)
  - 활성화된 조건에 맞는 세트만 표시
  - 전부 on 또는 전부 off = 전체 조회
  - [전체] = 모든 버튼 on으로 초기화
- 우측: [+ 티어 등록] 버튼 (bg-gray-800 컨테이너)

**카드 그리드** (5열, 월드컵과 동일):
```
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│  배우사진  │ │  작품커버  │ │  배우사진  │ │  작품커버  │ │          │
│          │ │          │ │          │ │          │ │  (빈 티어) │
│★마스터 배우│ │★마스터 작품│ │  일반  배우│ │  일반  작품│ │  일반  배우│
│종합 배우  │ │종합 작품  │ │연기파 티어 │ │장르별 티어 │ │새 티어    │
│245/300   │ │120/500   │ │30/45     │ │50/500    │ │0/300     │
│2026-10-01│ │2026-10-01│ │2026-10-05│ │2026-10-03│ │2026-10-07│
└──────────┘ └──────────┘ └──────────┘ └──────────┘ └──────────┘
```
- 썸네일: 최상위 티어 첫 번째 아이템의 사진/커버 (빈 티어는 기본 배경)
- 뱃지: ★마스터/일반 + 배우/작품 (색상 구분)
- 이름, 배치 현황 (배치수/전체수), 생성일
- 카드 클릭 → 티어 편집 화면 진입

- 좌측: 티어 라벨 (사용자 정의 색상 배경) — **클릭 시 편집 모달** (이름/색상 수정/삭제)
- 중앙: 배치된 아이템 (배우 사진 / 작품 커버), 드래그 앤 드롭으로 배치/이동
- 우측: ∧∨ 순서 이동 버튼 (하나의 영역에 위아래 배치)
- 하단: 미배치 아이템 풀
- 아이템 호버 시 CardTooltip 표시

**미배치 풀:**
- 10열 × 10행 그리드 (최대 100개 표시)
- 검색 없음
- 이미 배치된 아이템은 풀에서 제외
- 아이템을 티어에 배치 → 해당 카드 제거 → 뒤에서 앞으로 당겨짐 (99개, 98개...)
- [채움] 버튼 클릭 → 빈 자리에 다음 순서의 미배치 아이템 추가 → 다시 100개로
- 더 이상 채울 아이템이 없으면 [채움] 버튼 비활성화

**티어 라벨 클릭 시 편집 모달:**
```
┌─────────────────┐
│  티어 편집        │
│  이름 [S+     ]  │
│  색상 [■ 빨간색]  │
│    [삭제] [저장]  │
└─────────────────┘
```

### 마스터 티어
- 배우/작품 각 1개씩 고정 (삭제 불가)
- 전체 배우/작품 대상
- 상세 모달/툴팁에서 공식 티어로 표시

### 일반 티어
- 여러 개 생성 가능
- 생성 시 필터 조건 설정 (월드컵 필터와 동일 방식) → 조건은 생성 후 고정
- 배우/작품 타입 선택

## 배우/작품 티어 표시

### 카드 (Actors.tsx, Works.tsx)
- 이름/제목 오른쪽에 마스터 티어 뱃지: `배우명 [S+]`
- 뱃지 스타일: 티어 색상 배경 + 흰색 텍스트
- 미배치 시: `[-]` (회색 배경 뱃지)

### 상세 모달 (ActorDetailModal, WorkDetailModal)
- 배우명/작품명 오른쪽에 마스터 티어 뱃지: `배우명 [S+]`
- 뱃지 스타일: 티어 색상 배경 + 흰색 텍스트
- 미배치 시 표시 없음 또는 `-`

### CardTooltip
- 배우/작품명 오른쪽에 마스터 티어 표시: `배우명 S+`
- 텍스트 스타일: bold + 티어 색상 (배경 없이 문자 색상만)
- 미배치 시 표시 없음

## 고려 사항

- 마스터 티어는 타입별 1개만 → DB 레벨에서 트리거 또는 앱 레벨에서 체크
- 기존 월드컵/마스터랭킹과 독립 운영 — 데이터 충돌 없음
- 작품이 많으므로 미배치 풀은 100개씩 표시 + [채움] 버튼으로 추가 로딩
- 배우 soft delete된 항목은 티어에서도 숨김 처리
