# 임시폴더 등록 품번 파일 개별 이동

## 개요

임시폴더에 이미 DB에 등록된 품번의 파일이 있을 때, 해당 작품의 폴더로 파일을 개별 이동하는 기능.

## 전제 조건

- work_files에 파일/URL이 각각 1개씩만 있는 경우만 대상
- 다중 파일(파일 2개 이상, URL 2개 이상) 작품은 대상 제외 (수동 처리)

## 작품 상태 분류 (단일 파일/URL 기준)

등록된 작품의 work_files 상태 4가지:
- file_path만 있음 (로컬 파일 1개)
- url_path만 있음 (링크 1개)
- 둘다 있음 (로컬 1개 + 링크 1개) -> 다중 파일이므로 대상 제외
- 둘다 없음 (파일/링크 없이 작품 정보만)

## 케이스별 동작

### 1. file_path만 있는 경우 — 무조건 교체 방식

기존 file_path에서 폴더 경로를 추출하여 해당 폴더로 이동.
"있는 것만 교체" 원칙 — 분기 없이 단순 처리.

| 임시폴더 항목 | 동작 |
|---|---|
| 영상+이미지 | 기존 폴더 영상/이미지 전부 삭제 -> 새 영상/이미지 이동 -> work_files + cover_path 업데이트 |
| 영상만 | 기존 폴더 영상 삭제 -> 새 영상 이동 -> work_files 업데이트 (이미지 안 건드림) |
| 이미지만 | 기존 폴더 이미지 삭제 -> 새 이미지 이동 -> cover_path 업데이트 (영상 안 건드림) |

처리 후 임시폴더에서 해당 영상/이미지 파일 삭제.

### 2. url_path만 있는 경우

cover_path가 cover images/ 경로에 있는 경우만 대상.
cover images/ 상위 폴더(배우 폴더)를 기준으로 작품 폴더 생성 후 이동.
cover_path가 없거나 cover images/ 경로가 아니면 대상 제외.

| 임시폴더 항목 | 동작 |
|---|---|
| 영상+이미지 | 배우폴더 하위에 작품폴더 생성 -> 영상/이미지 이동 -> work_files에 local 추가 + cover_path를 새 작품폴더 이미지로 업데이트 + cover images/기존이미지 삭제 |
| 영상만 | 배우폴더 하위에 작품폴더 생성 -> 영상 이동 -> work_files에 local 추가 (cover_path 유지) |
| 이미지만 | cover images/ 기존 이미지 교체 -> cover_path 업데이트 |

처리 후 임시폴더에서 해당 영상/이미지 파일 삭제.

### 3. 둘다 있는 경우 — 대상 제외

다중 파일 (로컬 1개 + 링크 1개)이므로 수동 처리.

### 4. 둘다 없는 경우 — 대상 제외

이동할 대상 폴더를 알 수 없으므로 수동 처리.

## UI 트리거

기존 개별 자동 배치 버튼(>) 재활용:
- registeredWorkId 없음 -> 기존 자동 배치 (새 작품 등록)
- registeredWorkId 있음 -> 파일 이동 (기존 작품으로 교체/추가)
- 대상 제외 케이스 (다중 파일, 둘다 없음, url만+cover images 없음) -> disabled

일괄 버튼 1개 + 팝업 선택:
- 기존 일괄 자동 배치 버튼(>) 클릭 -> 팝업 표시
  - 신규등록: 미등록 품번만 대상 (기존 자동 배치)
  - 기존변경: 등록 품번만 대상 (파일 이동/교체)
- 퀵서치 팝업과 동일한 UX 패턴
