# 티어 제외 레벨 아이디어

## 개요
티어 에디터에 "제외" 고정 레벨을 추가하여 제외/해제를 티어 안에서 통합 관리.

## 설계
- 티어 목록 맨 아래에 **"제외" 레벨** 고정 (접힌 상태)
- 배우/작품 제외 시 → 기존 레벨에서 삭제되고 제외 레벨로 이동
- 제외 레벨에서 다른 레벨로 드래그 → 제외 해제 + 티어 복귀
- 일반 레벨에서 제외 레벨로 드래그 → 제외 처리
- is_excluded 플래그와 tier_items가 연동
- 티어 데이터(배치 위치)는 제외 시 삭제해도 됨 — 새로 올리면 바로 반영되므로

## 장점
- 제외/해제가 드래그로 직관적
- 제외된 배우/작품을 한눈에 확인 가능
