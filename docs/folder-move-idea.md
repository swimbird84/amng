# 파일트리 폴더 이동 기능

## 개요

파일트리에서 폴더를 드래그 앤 드롭으로 다른 폴더 아래로 이동하는 기능.

## 기본 원칙

- 트리의 모든 폴더는 드래그 가능, 다른 폴더에 드롭 가능
- 최상위 루트 폴더는 이동 불가
- 자기 자신이나 자기 하위 폴더로 이동 방지
- 임시폴더 드롭 인라인 UI가 떠있는 중에는 폴더 드래그 비활성
- 폴더 수정(이름 변경) 중에는 해당 폴더 드래그 비활성

## 드래그 소스 구분

- 임시폴더 파일 드래그 → 기존 작품 등록 플로우 (dataTransfer에 파일명 JSON)
- 트리 폴더 드래그 → 폴더 이동 플로우 (dataTransfer에 폴더 경로, 다른 키 사용)

## 이동 처리

파일시스템:
- fs.rename으로 폴더 이동 (같은 드라이브)
- 다른 드라이브면 복사 + 삭제 필요

DB 경로 갱신:
- work_files.file_path — 이동 폴더 하위 경로 일괄 UPDATE (prefix 치환)
- works.cover_path — 이동 폴더 하위를 가리키는 경우 일괄 UPDATE

## cover images 관련

- 배우 폴더 이동 시: 하위 cover images/ 포함 통째로 이동 → 별도 처리 불필요
- 작품 폴더 이동 시: cover images는 아카이빙 이후에만 존재 → 해당 없음

## UX

- 이동 전 확인 모달 표시
- 이동 후 트리에서 이동된 폴더 위치 자동 열기/스크롤
