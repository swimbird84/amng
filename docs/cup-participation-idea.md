# 마스터 대회 참가 조건 개선

## 채택 방향: 티어 기반 참가 조건

## 적용 대상: 작품 + 배우 마스터티어/대회 동시 적용

배우의 경우 기존에는 대회에서 빼려면 `is_excluded`로 목록 자체에서 숨겨야 했음.
티어 등급 제외를 도입하면 **목록에는 남기면서 대회만 불참**시킬 수 있어 유연해짐.

## 현재 상태

- `is_excluded = 1`인 작품/배우만 대회에서 자동 제외
- 그 외에는 모든 작품/배우가 참가 가능
- 티어 미등록이어도 대회 참가 가능

## 변경 목표 (마스터 대회 한정, 작품·배우 공통)

### 핵심 규칙
1. **티어 미등록 → 마스터 대회 불참** (티어 등록 강제 효과)
2. **티어 등급별 "대회 제외" 체크** → 해당 등급 전체 불참 (대회 규모 조절)

### 동작 방식
- 티어 에디터에서 각 등급(S, A, B, C, D, F 등)에 "대회 제외" 체크박스 추가
- 체크된 등급에 속한 항목은 마스터 대회 시작 시 참가 대상에서 자동 제외
- 티어에 등록되지 않은 항목도 자동 제외

### 참가 대상 판정 (작품·배우 공통)
```
마스터 대회 참가 가능 =
  is_excluded = 0
  AND 마스터 티어에 등록됨
  AND 등록된 티어 등급의 "대회 제외" 체크가 OFF
```

## 대회와 랭킹의 분리 원칙

### 대회: 시작 시점 스냅샷
- 대회 시작 시 참가 조건을 확인하여 `cup_entries`에 참가자 확정
- 이후 티어를 변경해도 **진행 중인 대회에는 영향 없음**
- 티어 변경은 **다음 대회부터** 반영

### 랭킹: 실시간 티어 기준 필터
- 랭킹 조회 시 현재 티어 상태를 기준으로 필터
- 티어 미등록 / 제외 등급 → **랭킹에서 완전히 제외** (순위 계산에서도 빠짐)
- `RANK()`가 조회 대상만으로 순위를 재산정하므로 순위 공백 없음

### 제외 → 복귀 시나리오
- 제외 등급으로 떨어지면 랭킹에서 사라짐 (포인트는 DB에 유지)
- 다시 참가 가능 등급으로 올라오면 기존 포인트와 함께 랭킹에 복귀
- 포인트 초기화 없음, 순위만 실시간 재계산

## 구현 범위

### DB
- `tier_levels` 테이블에 `is_cup_excluded` 컬럼 추가 (기본값 0)
- 작품/배우 구분 없이 `tier_levels`에 공통 적용 (tier_sets.type으로 구분됨)
- 기존 `cup_entries` 구조 변경 없음 (이미 시작 시점 스냅샷)

### 티어 에디터 UI
- 등급 헤더 클릭 시 뜨는 모달에 "대회 제외" 체크박스 추가
- 체크된 등급의 헤더에 SVG 금지 아이콘(🚫 스타일, currentColor) 표시
- 작품 티어 에디터, 배우 티어 에디터 양쪽 동일

### IPC — 마스터 대회 참가자 조회
- 대회 시작 시 참가자 쿼리에 티어 조건 추가:
  - `tier_items`에 존재하는 항목만 포함
  - 해당 `tier_level`의 `is_cup_excluded = 0`인 것만 포함
- 작품·배우 양쪽 쿼리 모두 수정

### IPC — 마스터 랭킹 조회
- `master-ranking:list` 쿼리 WHERE 조건에 티어 필터 추가:
  - 마스터 티어에 등록된 항목만 포함
  - 해당 등급의 `is_cup_excluded = 0`인 것만 포함
- 제외 대상은 `RANK()` 계산 전에 필터링 → 순위 공백 없음

### IPC — 대회 목록/UI
- 대회 목록 카드의 통계보기 (참가자 수 등) 에도 티어 조건 반영
- 대회 참가자 숫자 자동 계산 로직에 티어 필터 적용
- 대회 생성/설정의 드롭다운 박스 참가자 목록 쿼리에도 반영

### 영향받는 IPC 채널
- `master-ranking:list` — 메인 랭킹 조회 (actor/work 양쪽)
- `master-ranking:rank-trends` — 랭킹 추이
- `master-ranking:rank-history` — 개별 항목 랭킹 이력
- `master-ranking:item-stats` — 개별 항목 통계
- `master-ranking:item-format-stats` — 포맷별 통계
- `cup:item-count` — 참가자 숫자 자동 계산
- `cup:standings` — 대회 통계보기
- 대회 시작 관련 참가자 조회 쿼리
